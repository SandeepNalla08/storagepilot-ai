# StoragePilot AI

AI Copilot for Enterprise Storage Operations.

## Goal

StoragePilot AI is an AI-powered platform designed to help storage administrators monitor, troubleshoot, and automate enterprise storage environments.

The initial focus is NetApp ONTAP.

## Core Capabilities

- Connect to NetApp ONTAP through REST APIs
- Display storage inventory
- Monitor volumes and storage capacity
- Analyze storage alerts
- Explain storage problems in plain English
- Generate safe CLI and REST API commands
- Require administrator approval before executing changes
- Provide AI-powered troubleshooting recommendations

## Tech Stack

- Python
- FastAPI
- React
- PostgreSQL
- Docker
- NetApp ONTAP REST API
- AI / LLM
